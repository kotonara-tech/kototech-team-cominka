# 古民家解体の廃材活用：アイデア一覧とデモ台本

対象イベント：ことならテックカンファレンス 2026（2026-12-19、奈良市 BONCHI）。学生ブース展示・LT を想定する。

|---|---|---|---|
| A1 | 撮影だけで出品 | 写真から種類・材質候補・寸法・状態・説明文・用途案を推定し、出品データを作る | 実装 |

## 2. 他の案との違い

- 重量・価格を AI に推定させず、決まった表で計算する。同じ入力で同じ結果になり、出品者が寸法を直すと即座に再計算される
- 石綿含有のおそれがある建材を、写真の見た目ではなく「材料の種類」と「建物の築年」で止める。石綿の有無は写真では判定できないため
- 古民家ごとの来歴を商品価値として扱う

## 3. デモ台本（3 分）

1. 課題（30 秒）：奈良の古民家解体で出る梁・建具は処分されている。出品の手間・探す手段・石綿の 3 点が障害
2. 出品（60 秒）：スマホで出品画面を開き、解体現場「ならまちの町家」を選ぶ。A4 用紙を置いた古材を撮影 →「AI で鑑定」→ 寸法・材質・重量・価格・用途が埋まる。厚さを直すと重量と価格が変わる → 出品
3. 石綿の制限（30 秒）：メモに「スレート」と入れて鑑定 → 「出品できません（要分析調査）」。調査結果を「不検出」にすると出品できる
4. 購入（45 秒）：同じスマホで「マーケット」を開き（データは端末ごとに保存されるため）、「カウンターを作りたい」を選ぶ → 長さ 1,800 mm 以上の古材だけ表示 → 詳細で来歴・CO2・運搬目安を見せる → 購入希望を送る
5. まとめ（15 秒）：今後は秤連携・端材の組み合わせ・解体前予約

## 4. 展示の準備

- 古材の実物 1〜2 点と A4 用紙。会場の机で撮影できる大きさにする（板材・端材）
- 公開ページ https://ohru131.github.io/haizai/ をスマホで開き、右上の設定から Claude API キーを登録する。キーには Console で利用上限を設定しておく
- データは端末のブラウザごとに保存される。出品とマーケットは同じ端末で見せる。展示の前に設定画面の「デモデータを初期化」で戻す
- 通信できない場合は設定画面でキーを削除すると、デモ用推定で操作の流れを見せられる。展示後は展示端末からキーを削除する
