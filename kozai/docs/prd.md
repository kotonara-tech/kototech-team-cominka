# PRD：古材リレー（Kozai Relay）

- 作成者：ohru131
- 更新日：2026-11-15
- 状態：草案（ハッカソン用デモ）

## 1. 背景と課題

奈良県内には空き家となった古民家・町家が多く、解体時に柱・梁・板材・建具・瓦などが発生する。これらは DIY 利用者やアーティストにとって価値のある素材だが、現状は次の理由で大半が産業廃棄物として処分される。

- 解体業者に、1点ずつ寸法を測り、材質を見極め、説明文を書いて出品する時間がない
- 買い手（DIY 利用者・作家・店舗設計者）は「どこに・どんなサイズの古材があるか」を探す手段がない
- 古い成形板・スレート類には石綿（アスベスト）を含むものがあり、一般流通させてよい材と区別する仕組みがない

本プロダクトは「撮影から出品まで1分」を目標に、写真から寸法・材質・重量・用途例を自動で推定して出品データを作り、買い手が用途から古材を探せるようにする。

## 2. 対象ユーザー

| 役割 | 説明 | 主な目的 |
|---|---|---|
| 出品者 | 古民家の解体業者・古材業者・空き家の所有者 | 処分費を払っていた廃材を、手間をかけずに売る |
| 購入者 | DIY 利用者・アーティスト・店舗設計者 | 作りたいものに合うサイズと風合いの古材を探して買う |

## 3. 要件

| ID | 要件 | 優先度 |
|---|---|---|
| D1 | 出品者は廃材の写真を撮影またはアップロードできる | Must |
| D2 | システムは写真から種類・材質候補・寸法・状態・特徴・タイトル・説明文・用途案を推定する | Must |
| D3 | 写真に基準物（A4 用紙・名刺）を写すと、寸法をその大きさから推定する | Must |
| D4 | システムは寸法と材質の密度から重量の範囲を計算する。実測値を入力したら実測値を使う | Must |
| D5 | システムは材質・体積・状態から参考価格を計算する。出品者は価格を修正できる | Must |
| D6 | 出品者は推定結果を確認・修正してから出品する。修正すると重量・価格を再計算する | Must |
| D7 | 石綿含有のおそれがある建材（2006年9月より前の建物のスレート・ケイカル板・ビニル床タイル等）は、分析で「不検出」の結果がない限り出品できない | Must |
| D8 | 廃材は解体現場（古民家）にひも付き、購入者は来歴（地域・築年・部位）を見られる | Must |
| D9 | 購入者は種類・長さ・キーワードで廃材を検索できる | Must |
| D10 | 購入者は「作りたいもの」（カウンター・ベンチ・棚板など）から、寸法が合う廃材を逆引きできる | Must |
| D11 | 購入者は廃材に購入希望・問い合わせを送れる | Must |
| D12 | 木材は固定している CO2 量の目安を表示する | Should |
| D13 | 重量から運搬の目安（1人で運べる・2人・軽トラック）を表示する | Should |
| D14 | AI の API キーがない環境でも、デモ用の推定でひととおり操作できる | Must |
| D15 | 利用者は設定画面で Claude API キーを登録・確認・削除できる。キーはその端末のブラウザにだけ保存する | Must |
| D16 | 出品者は解体現場（名称・地域・築年・建物の種類）を追加できる。築年が不明な現場は 2006 年以前として出品可否を判定する | Must |
| D17 | 利用者は鑑定に使う AI を Claude・Gemini・OpenAI から選び、それぞれのキーとモデルを設定できる | Must |

## 4. やらないこと（スコープ外）

- 決済・配送の手配・取引の完了処理
- 利用者登録・ログイン・本人確認
- 石綿の有無の判定（写真から判定しない。おそれのある建材を出品させない判定だけを行う）
- 樹種の確定（候補として示し、出品者が確認する）
- 解体工事の見積・産業廃棄物の処理手続き

## 5. 成功の指標

- 撮影から出品完了までの操作時間が 1 分以内
- 推定寸法と実寸の差が、基準物ありで ±10% 以内（デモ素材 5 点で確認）
- デモで「作りたいもの → 該当古材 → 問い合わせ」が 3 操作以内で完了する

## 6. 名詞と動詞（設計への入力）

| 要件ID | 名詞（業務データ） | 動詞（業務の処理） |
|---|---|---|
| D1, D2, D3 | 写真、基準物、鑑定結果 | 鑑定する |
| D15 | API キー | 登録する、確認する、削除する |
| D16 | 解体現場 | 追加する |
| D17 | AI の種類・キー・モデル | 選ぶ、登録する |
| D4, D5, D12, D13 | 寸法、材質、重量、参考価格、CO2 固定量、運搬目安 | 見積もる |
| D6, D7 | 出品、石綿調査の結果 | 出品する、出品可否を判定する |
| D8 | 解体現場 | 一覧する |
| D9, D10 | 検索条件、作りたいもの（レシピ） | 検索する、逆引きする |
| D11 | 問い合わせ | 問い合わせる |

## 7. 制約

- 期限：ことならテックカンファレンス 2026（2026-12-19、奈良市 BONCHI）のブース展示
- 予算：AI の API 利用料のみ（デモ 1 回あたり数円）
- 技術：TypeScript、Claude API・Gemini API・OpenAI API（画像入力）、GitHub Pages。サーバー・DB・フレームワークは使わない（ブラウザ内で完結）
- 法規：石綿含有建材は大気汚染防止法・石綿障害予防規則の対象。一般向けに流通させない

## 8. 未決事項

- 実運用時の保管場所・引き渡し方法（現場渡し／倉庫）
- 参考価格の単価表の根拠（古材業者への聞き取りで決める）
