# ADR 0001：AI は写真から見て分かることだけを推定する

- 状態：採用
- 日付：2026-11-15

## 背景

写真から出品データを作るとき、重量・価格・出品可否まで AI に出させる方法と、AI の出力を計算の入力に限る方法がある。

## 決定

AI（Claude）が出すのは、種類・材質候補・寸法・寸法の根拠・状態・欠点・特徴・タイトル・説明文・用途案に限る。
重量・参考価格・CO2 固定量・運搬目安・出品可否は `src/domain` の材料表と計算式で求める。
AI の出力は strict tool use のスキーマで受け取り、材質は材料表のキーから選ばせる。

## 理由

- 同じ寸法・材質なら同じ重量・価格になり、根拠（密度・単価）を画面に出せる
- 出品者が寸法を直したとき、AI を呼び直さずに再計算できる
- 石綿含有のおそれの判定を AI の判断に任せない。写真では判定できず、誤って「問題なし」とした場合の影響が大きい

## 影響

- 材料表にない材質は「その他」として扱い、重量の誤差幅を大きく取る
- 材料表の値（密度・単価）を更新すると、既存の出品の見積も変わる。出品時の見積は出品データに保存して固定する
